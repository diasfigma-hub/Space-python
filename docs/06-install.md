# 6. Установка и запуск

## Что нужно

- Windows 10 или 11 (подойдёт и другая система, где есть Python);
- Python 3.10 или новее — [python.org/downloads](https://www.python.org/downloads/);
  при установке на Windows обязательно поставьте галочку **Add Python to PATH**;
- интернет нужен только для установки библиотеки, сама игра работает офлайн.

## Установка

Откройте командную строку (Win+R → `cmd`) и перейдите в папку с игрой:

```bat
cd "C:\путь\к\папке\games py"
```

Создайте виртуальное окружение — это необязательно, но так библиотеки не смешаются
с системными:

```bat
python -m venv venv
venv\Scripts\activate
```

Установите зависимости:

```bat
pip install -r requirements.txt
```

## Запуск

```bat
python main.py
```

Через пару секунд откроется окно 1280×720 с главным меню. Нажмите «Играть».

Игру можно запускать и двойным щелчком по файлу, если `main.py` связан с Python,
но надёжнее запускать из консоли: там видно сообщения об ошибках.

## Проверка, что всё правильно

- окно открылось, в меню видно название и кнопка «Играть»;
- по нажатию «Играть» сверху начинают падать астероиды;
- корабль двигается на WASD, по левой кнопке мыши летят жёлтые пули;
- после трёх попаданий астероид исчезает, очки растут;
- `Esc` открывает паузу, `Esc` её закрывает;
- после поражения кнопка «Играть снова» начинает новую игру.

Игра бесконечная: она идёт до последней жизни, рекорд не сохраняется — итоговый счёт
виден на экране поражения.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `python не является внутренней или внешней командой` | Python не добавлен в PATH. Переустановите его с галочкой **Add Python to PATH** |
| `ModuleNotFoundError: No module named 'pygame'` | Не установлена библиотека: `pip install -r requirements.txt` |
| `pip` не найден | Используйте `python -m pip install -r requirements.txt` |
| Окно не открывается, в консоли ошибка про картинки | Запускайте игру из папки проекта, не переносите `main.py` отдельно от папки `assets` |
| Игра идёт рывками | Закройте тяжёлые программы; игра сама подстраивается под скорость компьютера |
| Антивирус ругается на новый `.exe` | Проект запускается из исходного `.py`, собирать `.exe` не требуется |

## Как удалить

Достаточно удалить папку проекта целиком. В систему ничего не устанавливается,
кроме библиотеки Pygame в виртуальное окружение (если вы его создавали).
