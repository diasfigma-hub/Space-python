# 4. Устройство кода

Вся игра находится в одном файле `main.py` (388 строк). Классов нет: состояние игры
хранится в обычных переменных, а действия — в обычных функциях. Файл разбит на разделы:

1. настройки игры (константы);
2. загрузка картинок;
3. шрифты;
4. фон со звёздами;
5. переменные состояния игры;
6. функции логики;
7. функции отрисовки;
8. главный цикл `main()`.

## 4.1 Константы

| Константа | Значение | Смысл |
|---|---|---|
| `WIDTH`, `HEIGHT` | 1280, 720 | размер окна |
| `FPS` | 60 | кадров в секунду |
| `PLAYER_SPEED` | 340 | скорость корабля, пикселей в секунду |
| `BOOST_SPEED` | 560 | скорость корабля с ускорением на пробел |
| `BULLET_SPEED` | 900 | скорость пули |
| `SHOOT_DELAY` | 0,16 | пауза между выстрелами, секунд |
| `ASTEROID_SPEED` | (90, 140) | из этого диапазона берётся скорость астероида |
| `SPAWN_DELAY` | 0,9 | раз в столько секунд появляется новый астероид |
| `WHITE`, `CYAN`, `RED`, `TEXT_DIM` | цвета RGB | оформление интерфейса |

Константы сложности больше нет: скорость камней и пауза между ними постоянные.

## 4.2 Ресурсы

После `pg.init()` картинки загружаются один раз и хранятся в переменных:

- `ship_idle` — корабль стоит (`spaceship1.png`);
- `ship_fly` — корабль летит (`spaceship3.png`);
- `ship_boost` — корабль ускорился (`spaceship5.png`);
- `asteroid_images` — список из трёх картинок: целый, треснутый, обломки;
- `bullet_image` — жёлтый заряд (`bull1.png`).

Остальные картинки из `assets` (другие кадры корабля, синяя пуля) остались в проекте,
но код их не загружает.

Функция `load_image(folder, name, size)` собирает путь от папки с `main.py`:

```python
path = os.path.join(BASE_DIR, "assets", folder, name)
```

Благодаря этому игра работает, даже если запустить её не из своей папки.

## 4.3 Переменные состояния

| Переменная | Тип | Назначение |
|---|---|---|
| `state` | строка | текущий экран: `menu`, `playing`, `paused`, `over` |
| `player_x`, `player_y` | числа | положение корабля |
| `lives` | число | сколько жизней осталось |
| `score` | число | очки текущей игры |
| `asteroids` | список списков | астероиды на экране |
| `bullets` | список списков | пули игрока |
| `spawn_timer` | число | сколько секунд осталось до нового астероида |
| `shoot_timer` | число | сколько секунд осталось до следующего выстрела |

Один астероид — это список из четырёх чисел:

```python
[500, -80, 120, 3]   # x, y, скорость, прочность
```

Пуля — список из двух чисел: `[player_x, player_y - 62]`.

Кнопки экранов описаны прямо в коде через `pg.Rect`, чтобы по ним можно было проверять
клик: `play_rect`, `resume_rect`, `pause_menu_rect`, `again_rect`, `finish_menu_rect`.

## 4.4 Функции

| Функция | Что делает |
|---|---|
| `load_image(folder, name, size)` | загружает картинку и масштабирует её |
| `reset_game()` | сбрасывает жизни, очки и списки объектов, готовит новую игру |
| `spawn_asteroid()` | создаёт астероид за верхним краем экрана с прочностью 3 |
| `hit(x1, y1, r1, x2, y2, r2)` | проверяет, пересеклись ли два круга |
| `update_game(dt)` | один кадр игры: движение, стрельба, столкновения, очки, жизни |
| `draw_hud()` | надписи «Очки: N» и «Жизни: N» |
| `draw_game()` | фон, астероиды, пули, корабль и панель |
| `draw_button(text, rect)` | кнопка с подсветкой под курсором |
| `draw_overlay()` | тёмное затемнение для паузы и экрана поражения |
| `draw_menu()` | главное меню |
| `draw_pause()` | экран паузы |
| `draw_game_over()` | экран поражения с очками |
| `main()` | главный цикл игры |

Функций для мелочей нет намеренно: загрузка шрифтов, звёзды на фоне и выбор картинки
корабля написаны прямо в коде несколькими строками.

## 4.5 Что происходит за один кадр

```python
dt = min(clock.tick(FPS) / 1000, 0.05)
```

`dt` — время, прошедшее с прошлого кадра, в секундах. Все скорости умножаются на `dt`,
поэтому игра движется одинаково и на быстром, и на медленном компьютере.
Ограничение `0.05` не даёт объектам «телепортироваться», если окно на миг подвисло.

Дальше в `main()`:

1. `pg.event.get()` — забираем события (закрытие окна, нажатия, клики).
2. В зависимости от `state` обрабатываем ввод и меняем состояние.
3. На игровых экранах вызываем `update_game(dt)` — игра делает шаг вперёд.
4. Вызываем нужную функцию отрисовки.
5. `pg.display.flip()` — показываем готовый кадр.

## 4.6 Как двигается корабль

```python
keys = pg.key.get_pressed()
speed = BOOST_SPEED if keys[pg.K_SPACE] else PLAYER_SPEED
if keys[pg.K_w]:
    player_y -= speed * dt
```

Если зажат пробел, берётся скорость 560 вместо 340 — это и есть ускорение.
Остальные три направления устроены так же. Потом координаты ограничиваются,
чтобы корабль не улетел за экран:

```python
player_x = max(40, min(player_x, WIDTH - 40))
player_y = max(120, min(player_y, HEIGHT - 60))
```

## 4.7 Как работает стрельба

```python
shoot_timer -= dt
if pg.mouse.get_pressed()[0] and shoot_timer <= 0:
    bullets.append([player_x, player_y - 62])
    shoot_timer = SHOOT_DELAY
```

Зажатая левая кнопка мыши добавляет пулю, но не чаще, чем раз в 0,16 секунды —
иначе пули летели бы сплошной стеной. Каждый кадр пули поднимаются вверх и удаляются,
когда уходят за верхний край.

## 4.8 Столкновения

Все объекты считаются кругами: пуля — радиус 4, астероид — 28, корабль — 26.
Два круга пересекаются, если расстояние между центрами меньше суммы радиусов:

```python
def hit(x1, y1, r1, x2, y2, r2):
    dx = x1 - x2
    dy = y1 - y2
    return dx * dx + dy * dy < (r1 + r2) ** 2
```

Квадрат расстояния сравнивается с квадратом суммы радиусов, поэтому корень считать
не нужно — так быстрее и проще.

## 4.9 Прочность астероида и очки

Четвёртое число в списке астероида — прочность. Попадание пули уменьшает её на единицу:

```python
asteroid[3] -= 1
if asteroid[3] <= 0:
    asteroids.remove(asteroid)
    score += 10
```

Пока прочность 2 или 1, астероид остаётся на экране и просто меняет картинку.
Очки дают только за третье попадание:

```python
image = asteroid_images[3 - asteroid[3]]
```

При прочности 3 берётся картинка номер 0 (целый), при 2 — номер 1 (треснутый),
при 1 — номер 2 (обломки).

## 4.10 Потеря жизни

```python
for asteroid in asteroids[:]:
    if hit(player_x, player_y, 26, asteroid[0], asteroid[1], 28):
        asteroids.remove(asteroid)
        lives -= 1
```

Столкновение убирает астероид и отнимает одну жизнь. Когда жизней не осталось,
игра переключается на экран поражения:

```python
if lives <= 0:
    lives = 0
    state = "over"
```

## 4.11 Фон

Звёзды рисуются один раз при запуске на отдельной поверхности `background`,
а потом каждый кадр просто копируются на экран одной строкой `screen.blit(background, (0, 0))`.
Так фон выглядит одинаково на всех экранах и не требует отдельной функции обновления.
