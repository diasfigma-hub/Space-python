# 4. Основные модули и функции

Вся игра находится в одном файле `main.py`. Он разбит на разделы:

1. настройки игры (константы);
2. загрузка картинок;
3. шрифты;
4. фон и звёзды;
5. работа с файлом рекорда;
6. переменные состояния игры;
7. функции логики;
8. функции отрисовки;
9. главный цикл `main()`.

## 4.1 Константы

| Константа | Значение | Смысл |
|---|---|---|
| `WIDTH`, `HEIGHT` | 1280, 720 | размер окна |
| `FPS` | 60 | кадров в секунду |
| `PLAYER_SPEED` | 340 | скорость корабля, пикселей в секунду |
| `BOOST_SPEED` | 560 | скорость с ускорением |
| `BULLET_SPEED` | 900 | скорость пули |
| `SHOOT_DELAY` | 0,16 | пауза между выстрелами, секунд |
| `WAVES` | `(7, 1.10, 1.0)`, `(9, 0.90, 1.25)`, `(11, 0.72, 1.5)` | для каждой волны: сколько сбить, пауза между астероидами, множитель скорости |
| `WHITE`, `CYAN`, `YELLOW`, `RED`, `TEXT_DIM` | цвета RGB | оформление интерфейса |

## 4.2 Ресурсы

После `pg.init()` картинки загружаются один раз и хранятся в списках:

- `ships_1` — три кадра корабля первого уровня (покой, полёт, ускорение);
- `ships_2` — три кадра корабля второго уровня;
- `asteroid_images` — целый, треснутый астероид и обломки;
- `bullet_yellow`, `bullet_blue` — заряды первого и второго уровня.

Функция `load_image(folder, name, size)` собирает путь от папки с `main.py`:

```python
path = os.path.join(BASE_DIR, "assets", folder, name)
```

Благодаря этому игра работает, даже если запустить её не из своей папки.

## 4.3 Переменные состояния

Игра не использует классы: состояние хранится в обычных переменных модуля.

| Переменная | Тип | Назначение |
|---|---|---|
| `state` | строка | текущий экран: `menu`, `playing`, `paused`, `over`, `win` |
| `player_x`, `player_y` | числа | положение корабля |
| `lives` | число | сколько жизней осталось |
| `score` | число | очки текущей игры |
| `record` | число | лучший результат |
| `wave` | число | номер волны (1–3) |
| `wave_kills` | число | сколько астероидов сбито в этой волне |
| `level` | 1 или 2 | какой набор спрайтов корабля использовать |
| `asteroids` | список словарей | астероиды на экране |
| `bullets` | список списков | пули игрока |
| `particles` | список словарей | частицы взрывов |
| `stars` | список списков | звёзды фона |
| `spawn_timer`, `shoot_timer` | числа | таймеры появления астероидов и выстрелов |
| `invuln_timer`, `flash_timer`, `wave_banner` | числа | неуязвимость, вспышка, надпись «ВОЛНА N» |

Один астероид — это словарь:

```python
{"x": 500, "y": -80, "hp": 3, "speed": 90.0, "angle": 12.0, "spin": -20.0}
```

Пуля — просто пара координат `[x, y]`. Частица — словарь с координатами, скоростью,
временем жизни и цветом.

## 4.4 Функции

### Логика

| Функция | Что делает |
|---|---|
| `reset_game()` | сбрасывает жизни, очки, списки объектов и запускает первую волну |
| `start_wave(number)` | задаёт номер волны, обнуляет счётчик сбитых, включает надпись и выбирает уровень корабля |
| `spawn_asteroid()` | создаёт новый астероид со случайным `x`, скоростью и вращением |
| `shoot()` | добавляет пулю над кораблём и запускает задержку стрельбы |
| `explode(x, y, count, color)` | создаёт облако частиц в точке |
| `circles_hit(x1, y1, r1, x2, y2, r2)` | проверяет пересечение двух кругов |
| `finish_game(player_won)` | переключает игру на экран победы или поражения и сохраняет рекорд |
| `player_image()` | выбирает кадр корабля по нажатым клавишам и уровню |
| `update_playing(dt)` | главная функция игрового процесса за один кадр |

### Ресурсы и фон

| Функция | Что делает |
|---|---|
| `load_image(folder, name, size)` | загружает и масштабирует картинку |
| `make_font(size, bold)` | создаёт шрифт нужного размера |
| `make_nebula()` | рисует туманность один раз при запуске |
| `make_stars()` | создаёт список звёзд |
| `update_stars(dt)` | двигает звёзды вниз и возвращает улетевшие наверх |
| `load_record()`, `save_record(value)` | читают и записывают файл рекорда |

### Отрисовка

| Функция | Что рисует |
|---|---|
| `draw_background()` | фон-туманность и звёзды |
| `draw_world()` | астероиды, пули, частицы, корабль |
| `draw_hud()` | очки, рекорд, жизни, номер волны, надписи |
| `draw_button(text, rect, mouse_pos)` | кнопку с подсветкой под курсором |
| `draw_dark_overlay()` | полупрозрачное затемнение |
| `draw_menu(mouse_pos)` | главное меню |
| `draw_pause(mouse_pos)` | экран паузы |
| `draw_finish(player_won, mouse_pos)` | экраны победы и поражения |

## 4.5 Что происходит за один кадр

```python
dt = min(clock.tick(FPS) / 1000, 0.05)
```

`dt` — время, прошедшее с прошлого кадра, в секундах. Все скорости умножаются на `dt`,
поэтому игра движется одинаково и на быстром, и на медленном компьютере.
Ограничение `0.05` не даёт объектам «телепортироваться», если окно на миг подвисло.

Дальше:

1. `pg.event.get()` — забираем события (закрытие окна, нажатия, клики).
2. `update_stars(dt)` — двигаем фон, он живёт на всех экранах.
3. В зависимости от `state` обрабатываем ввод и меняем состояние.
4. Рисуем фон, объекты, панель и, если нужно, наложение (пауза, победа, поражение).
5. `pg.display.flip()` — показываем готовый кадр.

## 4.6 Столкновения

Столкновения считаются по кругам — это дешево и достаточно точно для круглых камней:

```python
def circles_hit(x1, y1, r1, x2, y2, r2):
    dx = x1 - x2
    dy = y1 - y2
    return dx * dx + dy * dy < (r1 + r2) ** 2
```

Радиусы: пуля — 4, астероид — 28, корабль — 26.
Квадрат расстояния сравнивается с квадратом суммы радиусов, поэтому корень не нужен.

## 4.7 Подсчёт очков

```python
score += 10
wave_kills += 1
```

Очки начисляются только при уничтожении астероида, счётчик `wave_kills` нужен,
чтобы понять, когда волна выполнена. Когда `wave_kills` достигает нужного числа
и список `asteroids` пуст, вызывается `start_wave(wave + 1)` или `finish_game(True)`.

## 4.8 Хранение рекорда

```python
with open(os.path.join(BASE_DIR, "record.txt"), "w", encoding="utf-8") as file:
    file.write(str(value))
```

Чтение обёрнуто в `try/except`: если файла нет или в нём мусор, игра просто начинает
с рекорда 0 и не падает. Запись тоже защищена — если папка недоступна для записи,
игра продолжает работать без сохранения рекорда.
