# 2. Используемые технологии

## Python 3

Основной язык проекта. Используются только стандартные модули:

- `os` — сборка путей к картинкам;
- `random` — случайное положение и скорость астероидов, расположение звёзд.

Проверено на Python 3.14.2 под Windows 10/11. Подойдёт любая версия 3.10 и новее.

## Pygame

Библиотека для двухмерных игр: даёт окно, отрисовку картинок, шрифты, работу с клавиатурой,
мышью и временем. В проекте установлена **pygame-ce 2.5.8** — современная сборка Pygame,
которая подключается точно так же: `import pygame as pg`.

Что именно используется:

| Возможность Pygame | Где применяется |
|---|---|
| `pg.display.set_mode` | создание окна 1280×720 |
| `pg.image.load` + `pg.transform.scale` | загрузка и масштабирование спрайтов |
| `pg.Surface` | фон со звёздами и полупрозрачное затемнение экранов |
| `pg.draw.circle`, `pg.draw.rect` | звёзды на фоне, кнопки |
| `pg.font.SysFont` | надписи интерфейса |
| `pg.event.get` | закрытие окна, нажатия клавиш и мыши |
| `pg.key.get_pressed`, `pg.mouse.get_pressed` | движение, ускорение и огонь |
| `pg.time.Clock` | ограничение 60 кадрами в секунду и расчёт `dt` |
| `pg.display.flip` | показ готового кадра |

Pygame выбран потому, что он простой, бесплатный, ставится одной командой
(`pip install pygame-ce`) и хорошо подходит для обучения: весь игровой цикл виден в коде,
без скрытой «магии» движка.

## Aseprite

Графический редактор для пиксель-арта. В нём нарисованы спрайты корабля; исходный файл
`spaceship.aseprite` лежит в корне проекта. Остальные картинки — PNG.

## Что сознательно не использовалось

- **Классы и сложные паттерны** — игра укладывается в процедурный код, который проще объяснить.
- **Сторонние движки (Unity, Godot)** — избыточны для такой задачи.
- **Сервер, база данных, сеть** — не нужны для одиночной игры.
- **Тяжёлые библиотеки (numpy, OpenGL)** — не требуются.
- **Система частиц и вращение спрайтов** — убраны, потому что не влияют на правила игры,
  а код усложняют.

## Минимальные требования

- Windows 7/10/11 (проверено на Windows);
- Python 3.10+;
- Pygame 2.x;
- 50 МБ свободного места, отдельная видеокарта не требуется.
